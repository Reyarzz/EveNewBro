# Install EVE NewBro

**You do not need to clone this repo or run any build scripts.**

Open **[Latest release](https://github.com/Reyarzz/EveNewBro/releases/latest)** and pick the file for your system.

> **Note:** Every release also lists automatic **Source code (zip)** and **Source code (tar.gz)** links from GitHub. Ignore those for playing — scroll to the **Assets** section for the installer (`.exe` or `.dmg`).

---

## Windows

1. Download **`EVE-NewBro-Setup-….exe`**
2. Run the installer
3. Launch **EVE NewBro** from the desktop or Start menu
4. Run EVE in **windowed** or **borderless fullscreen**

**SmartScreen** (unsigned app): **More info → Run anyway**

Once installed, the app **updates itself automatically** from new releases — no need to re-download.

---

## macOS

1. Download the `.dmg` for your Mac:
   - **`…-arm64.dmg`** — Apple Silicon (M1/M2/M3/M4)
   - **`…-x64.dmg`** — Intel Mac
2. Open the `.dmg`, drag **EVE NewBro** to **Applications**
3. First launch: **right-click the app → Open** (unsigned app — Gatekeeper)
4. Run EVE in **windowed** or **borderless fullscreen**

Alternatively use the matching **`.zip`** if you prefer a folder without the dmg wizard.

---

## Optional: EVE login

Open the **Me** tab and sign in with EVE SSO for wallet, skills, mail, and multi-character features. Most tabs work without login.

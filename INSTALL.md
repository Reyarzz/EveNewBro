# Install EVE NewBro (Windows)

**You do not need to clone this repo or run `build.bat`.**

## Download and run

1. Open **[Latest release](https://github.com/Reyarzz/EveNewBro/releases/latest)** on GitHub.
2. Under **Assets**, download **`EVE-NewBro-Setup-….exe`**.
3. Run the installer (pick a folder if asked).
4. Launch **EVE NewBro** from the desktop or Start menu shortcut.
5. Run EVE in **windowed** or **borderless fullscreen** so the overlay stays on top.

### Windows SmartScreen

The app is **not code-signed** yet. On first run Windows may show “Windows protected your PC”:

- Click **More info** → **Run anyway**

That is normal for unsigned indie tools.

### Optional: EVE login

Open the **Me** tab and sign in with EVE SSO if you want wallet, skills, mail, or multi-character features. Most tabs work without login.
